# 今天吃什么？

一个无需安装、打开即用的随机美食抽取小网页。转动轮盘，让它帮你结束“今天吃什么”的选择困难。

## 功能

- 内置 8 种常见餐食候选项。
- 点击按钮随机抽取，并以轮盘动画展示结果。
- 展示对应的用餐小提示。
- 响应式布局，适合桌面和手机浏览器。
- 不依赖第三方库或网络资源。

## 使用方法

1. 克隆或下载本仓库。
2. 在浏览器中直接打开 `index.html`。
3. 点击 **“帮我决定！”**，等待轮盘停止，即可查看本次推荐。
4. 若不满意，点击 **“再抽一次”** 重新抽取。

也可以在项目目录启动一个本地静态服务器：

```bash
python3 -m http.server 8000
```

然后在浏览器访问 <http://localhost:8000>。

## 自定义菜单

在 `index.html` 的 `foods` 数组中修改、增加或删除餐食对象，即可定制自己的候选菜单。每个对象包含：

- `name`：餐食名称。
- `hint`：抽中后显示的提示文案。
